# Xojo Console Project — Format Reference

A Xojo **Console** project saved by the IDE in text project format (Xojo 2026r3+). Every file is unedited IDE output.

- **Use it as a reference, not a template.** Don't copy this project or its files. Read them to see how the IDE
  writes each file type, then write your own files the same way.
- **Check the files, not your memory.** When unsure about a tag, indent, blank line or event signature, open the
  matching file here.
- `ConsoleAppStructure.xojo_project` is the manifest that lists every item. `Module1.xojo_code` has one of every
  member type. Each `Custom….xojo_code` file subclasses one framework class (Timer, Thread, sockets, Shell, …)
  with all of its event handlers. The other files cover the remaining item types (file types, build steps).
- Don't edit the binary files (`.xojo_resources`, `.xojo_uistate`).
